# 5.EDA_3_Candidate 해설

## 1. 분석 목적

`5.EDA_3_Candidate.ipynb`의 목적은 Normal 데이터의 `AI2_Current`에서 관찰되는 반복적인 신호 구조가 실제로 존재하는지 검증하는 것이다.

이 단계에서는 약 1.6~1.7초의 반복을 실제 Fine Blanking 공정의 1 Cycle 또는 1 Stroke라고 가정하지 않는다.

검증하고자 하는 것은 다음과 같다.

> **Normal AI2_Current에 데이터상 안정적으로 반복되는 파형 및 시간 구조가 존재하는가?**

따라서 본 분석에서는 다음 표현을 사용한다.

- AI2 반복 패턴
- 반복주기 후보
- 반복 파형
- 반복 시간구조
- 동일 또는 유사 위상

반면 다음 표현은 아직 사용하지 않는다.

- Fine Blanking Cycle
- Press Cycle
- Stroke 주기
- 실제 공정 1회 주기

실제 공정주기와의 대응을 확정하려면 Ram Position, PLC Cycle Counter, 생산속도 또는 현장 운전정보 등 외부 기준이 추가로 필요하다.

---

# 2. 분석 전제

이전 Gap 검증을 통해 Normal 데이터는 하나의 완전히 연속적인 시계열이 아니라 여러 개의 연속 Segment로 구성되어 있음을 확인하였다.

따라서 본 분석에서는 다음 원칙을 유지하였다.

1. Gap을 넘어 신호를 연결하지 않는다.
2. Gap 구간을 보간하지 않는다.
3. 각 `segment_id` 내부에서만 반복구조를 분석한다.
4. Segment 시작점을 실제 공정 시작점으로 해석하지 않는다.
5. AI2_Current의 물리적 단위가 제공되지 않았으므로 절대값의 물리적 의미를 임의로 부여하지 않는다.

현재 데이터의 저장 간격은 약 0.1초이므로, 약 1.7초의 반복은 약 17 samples에 해당한다.

# 3. 전체 Normal AI2 Raw 신호 확인

먼저 별도의 Cycle Detector를 적용하지 않고 Normal `AI2_Current` Raw 신호 자체를 확인하였다.

목적은 알고리즘이 반복구조를 만들어내기 전에 실제 데이터에서 반복적인 상승·하강 형태가 관찰되는지 확인하는 것이다.

전체 시계열 및 여러 연속 Segment를 확인한 결과, AI2_Current에서 단순한 Random Noise와는 다른 반복적인 상승·하강 구조가 관찰되었다.

그러나 이 단계는 육안 관찰이므로 반복주기를 확정하는 근거로 사용하지 않았다.

# 4. 50-sample Segment 분석

Normal 데이터에는 최대 50 samples 길이의 Segment가 반복적으로 존재한다.

50-sample Segment는 총 **202개** 확인되었다.

저장 간격이 약 0.1초이므로 하나의 50-sample Segment는 약 4.9초의 시간 범위를 가진다.

이들 Segment를 동일한 상대시간 기준으로 Overlay하여 AI2 파형을 비교하였다.

## 결과

다수의 Segment에서 유사한 상승·하강 구조가 반복적으로 관찰되었다.

특히 약 4.9초의 Segment 내부에서 약 1.6~1.7초 간격의 구조가 여러 번 반복되는 형태가 나타났다.

대략적으로 다음과 같은 시간 구조가 관찰되었다.

```text
0.0 sec
  ↓
약 0.8~0.9 sec : 변화량 극점
  ↓
약 1.6~1.7 sec : 시작 수준 부근으로 복귀
  ↓
약 2.5~2.6 sec : 다음 변화량 극점
  ↓
약 3.3 sec     : 다시 복귀
  ↓
약 4.2 sec     : 다음 변화량 극점
```

즉 약 4.9초의 Segment 안에 약 3회의 반복구조가 포함되는 형태가 관찰되었다.

단, 이 결과만으로는 50-sample이라는 Segment 길이 자체가 반복구조를 인위적으로 만들어냈을 가능성을 배제할 수 없다.

# 5. Segment 시작점 `(0, 0)` 정렬

각 Segment의 파형 형태를 직접 비교하기 위해 시작점을 `(0, 0)`으로 이동시켰다.

시간축은 다음과 같이 변환하였다.

```python
x = elapsed_sec - first_elapsed_sec
```

AI2_Current는 다음과 같이 변환하였다.

```python
y_shifted = AI2_Current - first_AI2_Current
```

따라서 모든 Segment의 첫 번째 관측점은 `(0, 0)`이 된다.

## 주의

이 변환은 정규화가 아니다.

Amplitude를 동일하게 만들거나 파형을 변형한 것이 아니라 각 Segment의 첫 관측점을 좌표계의 원점으로 평행이동한 것이다.

따라서 `(0, 0)` 자체는 분석자가 인위적으로 만든 기준점이다.

> **Segment 시작점 `(0, 0)`을 실제 공정 시작점으로 해석해서는 안 된다.**

## 결과

시작점을 정렬한 이후에도 다음 구조가 반복적으로 나타났다.

- 약 0.8~0.9초에서 시작 수준으로부터 크게 이탈
- 약 1.6~1.7초에서 다시 시작 수준 부근으로 복귀
- 약 2.5초에서 다시 크게 이탈
- 약 3.3초에서 다시 시작 수준 부근으로 복귀
- 이후 동일한 형태 반복

첫 번째 `(0, 0)`은 인위적으로 만든 값이지만, 이후 약 1.7초와 3.3초 부근에서 다시 여러 파형이 수렴하는 현상은 강제로 만든 것이 아니다.

# 6. 절대 변화량 `|ΔAI2|` 검증

상승 방향과 하강 방향의 파형이 서로 상쇄되어 반복구조처럼 보이는 가능성을 확인하기 위해 각 Segment의 시작값 대비 절대 변화량을 계산하였다.

```text
|ΔAI2| = |AI2(t) - AI2(0)|
```

그리고 모든 50-sample Segment에 대해 Median 및 IQR을 계산하였다.

## 결과

절대값을 사용하여 방향성을 제거한 이후에도 반복적인 구조가 유지되었다.

대표적인 형태는 다음과 같았다.

```text
0.0 sec      → 변화량 0

약 0.8 sec   → |ΔAI2| 증가
약 1.7 sec   → |ΔAI2| 감소

약 2.5 sec   → |ΔAI2| 증가
약 3.3 sec   → |ΔAI2| 감소

약 4.2 sec   → |ΔAI2| 증가
```

따라서 관찰된 반복구조가 단순히 상승 파형과 하강 파형의 상쇄 때문에 발생했다고 보기 어렵다.

---

# 7. UP / DOWN 형태 분리

Segment 시작 이후 약 0.8초 지점의 AI2 변화 방향을 기준으로 50-sample Segment를 두 그룹으로 나누어 확인하였다.

- UP: 약 0.8초 지점의 변화량이 양수
- DOWN: 약 0.8초 지점의 변화량이 음수

결과는 다음과 같다.

```text
UP   : 97 segments
DOWN : 105 segments
```

두 그룹은 거의 비슷한 수로 나타났다.

## 결과

UP 그룹에서는 약 0.8~0.9초 부근에서 양의 방향으로 크게 변화한 후 약 1.7초에서 시작 수준 부근으로 복귀하였다.

DOWN 그룹에서는 반대로 약 0.8초 부근에서 음의 방향으로 크게 변화한 후 약 1.7초에서 시작 수준 부근으로 복귀하였다.

즉 방향은 서로 반대지만 두 그룹 모두 유사한 반복 시간구조를 보였다.

## 해석

따라서 Normal AI2 반복구조를 단순히 `Positive Peak → Positive Peak`로 정의하는 것은 적절하지 않을 가능성이 있다.

공통적인 특징은 Peak의 부호보다 다음과 같은 시간 및 위상 구조에 가깝다.

```text
기준 수준
    ↓
변화
    ↓
극점
    ↓
복귀
    ↓
약 1.7초 후 유사 위상
```

단, UP/DOWN 분류 자체는 0.8초 시점의 부호를 이용하여 만든 분석용 구분이므로 이를 서로 다른 실제 공정상태라고 해석하지 않는다.

# 8. Short Segment 검증

50-sample Segment에서 관찰된 반복성이 Segment 길이 자체에 의해 발생한 현상인지 확인하기 위해 50 samples 미만의 Normal Segment도 별도로 분석하였다.

Normal 데이터에는 **400개의 Short Segment**가 존재하였다.

이들 Segment에서도 Raw Overlay 및 시작점 `(0, 0)` 정렬을 수행하였다.

## 결과

50 samples 미만의 Segment에서도 동일한 형태의 반복구조가 관찰되었다.

특히 데이터가 존재하는 범위에서 다음과 같은 구조가 반복되었다.

- 약 0.8초 부근에서 변화량 증가
- 약 1.6~1.7초 부근에서 시작 수준으로 복귀
- 충분히 긴 Short Segment에서는 약 3.3초 부근에서 추가 복귀

## 해석

따라서 약 1.6~1.7초 반복구조가 정확히 50-sample이라는 Segment 길이 때문에 인위적으로 만들어졌을 가능성은 낮아졌다.

즉 반복구조는 50-sample Segment에만 한정된 현상이 아니라 Normal AI2 데이터의 보다 일반적인 특성으로 판단하였다.

# 9. 반복주기 정량 검증

앞선 분석은 주로 파형 Overlay를 이용한 시각적 검증이었다.

따라서 약 1.6~1.7초 반복구조가 실제로 여러 Normal Segment에서 정량적으로 재현되는지 확인하기 위해 Segment별 ACF 기반 반복주기 분석을 수행하였다.

탐색 범위는 육안으로 관찰된 반복구조 주변인 약 1.2~2.2초로 설정하였다.

각 Segment에서 해당 범위의 자기상관을 계산하고 가장 높은 상관을 나타내는 Lag를 반복주기 후보로 추정하였다.

## 결과

전체 Normal Segment는 **602개**이며, 충분한 길이를 가져 반복주기를 계산할 수 있었던 Segment는 **423개**였다.

반복주기 결과는 다음과 같다.

```text
계산 가능 Segment : 423

1.6 sec :   2 segments
1.7 sec : 421 segments
```

즉 계산 가능한 423개 Segment 모두 1.6~1.7초 범위에 포함되었으며, 이 중 421개가 1.7초로 추정되었다.

대표 통계는 다음과 같다.

```text
Mean period              ≈ 1.6995 sec
Median period            = 1.7 sec
Standard deviation       ≈ 0.0069 sec
Median ACF correlation   ≈ 0.992
```

## 해석

육안으로 관찰되었던 약 1.6~1.7초 반복구조가 일부 Segment에서만 나타나는 현상이 아니라 분석 가능한 Normal Segment 전반에서 매우 안정적으로 재현되었다.

특히 ACF correlation 중앙값이 약 0.992로 나타나 약 1.7초의 시간 이동 후 파형 간 유사성이 매우 높았다.

따라서 다음을 정량적으로 확인하였다.

> **Normal AI2_Current에는 약 1.7초의 매우 안정적인 반복 시간구조가 존재한다.**

단, 이는 AI2 신호의 반복 시간구조를 의미하며 실제 Fine Blanking 공정의 1 Cycle 또는 1 Stroke와 동일하다는 의미는 아니다.

# 10. Segment 시작 위상 검증

앞선 `(0, 0)` Overlay에서 각 Segment가 시작된 이후 약 1.7초마다 시작 수준 부근으로 복귀하는 현상이 관찰되었다.

따라서 Segment 시작점과 AI2 반복파형 사이에 일정한 위상 관계가 존재하는지 추가로 검증하였다.

각 Segment에서 다음 값을 계산하였다.

```text
Return Error
=
|AI2(t + lag) - AI2(t)|
/
Segment AI2 Range
```

즉 Segment 전체 변동폭과 비교하여 특정 시간이 지난 뒤 AI2가 시작 수준에 얼마나 가까워지는지를 계산하였다.

---

## 10.1 1.7초 Return Error

1.7초 이후까지 데이터가 존재하여 비교 가능한 Segment는 **462개**였다.

대표 결과는 다음과 같다.

```text
Comparable segments               : 462

Median absolute return error      : 12.74
Median normalized return error    : 0.0391

Q1 normalized return error        : 0.0234
Q3 normalized return error        : 0.0550
Maximum normalized return error   : 0.1018
```

Median normalized return error는 약 0.039이다.

즉 전형적인 Normal Segment에서는 약 1.7초 후 AI2 값이 시작점으로부터 해당 Segment 전체 변동폭의 약 **3.9% 수준의 차이**까지 복귀하였다.

또한 75%의 Segment가 약 5.5% 이하의 복귀오차를 나타냈다.

---

# 11. 다른 시간 Lag와의 대조검증

1.7초에서 시작값과 비슷해지는 현상이 단순히 AI2가 천천히 변화하기 때문에 발생한 것인지 확인하기 위해 다른 시간 Lag와 비교하였다.

비교한 시간은 다음과 같다.

```text
0.5 sec
0.8 sec
1.0 sec
1.7 sec
2.0 sec
```

Median normalized return error는 다음과 같이 나타났다.

| Time Lag | Median Return Error |
|---:|---:|
| 0.5 sec | 0.577 |
| 0.8 sec | 0.708 |
| 1.0 sec | 0.671 |
| **1.7 sec** | **0.039** |
| 2.0 sec | 0.407 |

## 해석

0.5~1.0초에서는 AI2가 Segment 시작 수준으로부터 크게 이탈하였다.

특히 약 0.8초에서는 Segment 전체 변동폭 대비 약 70.8% 수준의 차이를 나타냈다.

그러나 약 1.7초에서는 Return Error가 약 3.9%까지 급격히 감소하였다.

그리고 2.0초에서는 다시 약 40.7%까지 증가하였다.

즉 다음과 같은 구조가 정량적으로 확인되었다.

```text
Segment 시작
     │
     ├── 0.5 sec → 시작 수준에서 멀어짐
     │
     ├── 0.8 sec → 크게 이탈
     │
     ├── 1.0 sec → 여전히 크게 이탈
     │
     ├── 1.7 sec → 시작 수준 부근으로 복귀
     │
     └── 2.0 sec → 다시 이탈
```

따라서 1.7초 후 시작값과 유사해지는 현상은 단순히 신호 변화가 느리기 때문이라기보다 AI2 반복파형의 특정 시간 및 위상 구조와 관련된 것으로 판단하였다.

# 12. Candidate 최종 결론

본 분석을 통해 Normal `AI2_Current`에서 다음 사실을 확인하였다.

1. Raw 신호에서 반복적인 상승·하강 구조가 관찰되었다.
2. 50-sample Segment Overlay에서 약 1.6~1.7초 간격의 반복구조가 나타났다.
3. Segment 시작점을 `(0, 0)`으로 정렬한 이후에도 약 1.7초 및 3.3초 부근에서 반복적인 복귀 구조가 나타났다.
4. `|ΔAI2|` 분석에서도 동일한 시간구조가 유지되어 UP/DOWN 상쇄에 의한 현상일 가능성이 낮아졌다.
5. UP/DOWN 파형 모두 유사한 반복 시간구조를 보여 Positive Peak만으로 반복구조를 정의하는 것은 적절하지 않을 가능성이 확인되었다.
6. 50 samples 미만의 Short Segment에서도 동일한 반복성이 나타나 50-sample Segment 길이에 의해 발생한 인공적인 패턴일 가능성이 낮아졌다.
7. Segment별 ACF 분석에서 분석 가능한 423개 Segment 모두 1.6~1.7초의 반복주기를 나타냈으며, 421개는 1.7초로 추정되었다.
8. ACF correlation 중앙값은 약 0.992로 나타났다.
9. Segment 시작점 기준 약 1.7초 후 Return Error 중앙값은 전체 Segment 변동폭의 약 3.9%였다.
10. 0.5, 0.8, 1.0, 2.0초와 비교했을 때 1.7초에서만 Return Error가 매우 작아지는 구조가 확인되었다.

따라서 본 단계의 최종 결론은 다음과 같다.

> **Normal AI2_Current에는 약 1.7초의 매우 안정적인 반복 시간구조가 존재한다. 또한 각 연속 Segment의 시작점은 해당 반복파형과 일정한 위상 관계를 갖는 형태로 관찰된다. 따라서 AI2_Current를 Normal 데이터의 반복구조를 탐색하기 위한 기준 신호 후보로 사용할 근거가 확보되었다.**
